# 🔥 EarnKro Telegram Bot

A clean and modern Telegram affiliate bot built with Python.

This bot converts shopping/product links into affiliate links using the Ekaro API.

---

# ✨ Features

- 🔗 Instant affiliate link conversion
- 🖼 Image + caption support
- 🎥 Video + caption support
- 📄 Document + caption support
- ⚡ Fast and lightweight
- 🚀 Clean Telegram UI
- 📢 Channel & support buttons

---

# 📦 Tech Stack

- Python
- python-telegram-bot
- Requests
- Ekaro API
